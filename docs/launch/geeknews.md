## 제목 (80자 이내)
claude-drift: 내 Claude Code 세션을 새 모델로 재생해 "진짜 달라진 행동"만 골라내는 CLI

## 본문

새 Claude 모델이 나올 때마다 "행동이 달라졌다"는 말은 많지만, 내 작업에서 뭐가 달라졌는지 재는 도구는 없었습니다. claude-drift는 `~/.claude/projects`에 이미 쌓여 있는 세션 로그를 그대로 재료로 씁니다. 사람이 친 프롬프트 직전까지의 맥락을 새 모델에 주고 "다음 행동 하나"만 받은 뒤(도구는 실행하지 않음), 기록된 행동과 비교합니다. 설정 파일도 API 키도 없고 기존 `claude` 로그인만 씁니다.

핵심은 대조군입니다. 같은 컷을 옛 모델로도 재생해 노이즈 밴드를 만들고, 옛 모델을 5번 재생하는 `--self-replays`로 모델 자체의 불안정성까지 따로 잽니다. 그 결과가 흥미로웠습니다.

- Opus 5는 자기 자신을 80% 재현합니다 (5회 재생, 밴드 63~88%).
- 그런데 자기가 기록한 대화형 세션의 행동과는 35%만 일치합니다.
- 즉 대조군 없이 "새 모델이 65% 다르게 행동한다"고 말하면, 그 숫자의 대부분은 모델이 아니라 재생 환경(`claude -p`, 훅·플러그인 상태, 사고 예산)을 재는 것입니다.
- Sonnet 5는 이 밴드 안에 있어서, 20턴 기준으로 검출 가능한 드리프트가 없었습니다.

전이별 변화는 세션 단위 부트스트랩 구간과 Bonferroni 보정을 거쳐 REAL/NOISE로 나뉩니다. 한계도 분명합니다. 단일 스텝 재생이라 이어지는 작업 결과는 못 보고, `-p` 모드가 대화형과 다르며, 훅이 병합되어 기계 간 비교는 어렵고, 30턴 기본 실행이 구독 창의 상당 부분을 씁니다.

설치: `uvx claude-drift scan`

리포트 예시와 방법 설명은 README에 있습니다. 같은 실험을 본인 세션으로 돌려 보시고 숫자가 어떻게 나오는지 공유해 주시면 예시로 링크하겠습니다.
